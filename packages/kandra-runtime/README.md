# kandra-runtime

<!-- TODO: hyperlink "Kandra" to the repository once it has a public home. -->
Runtime library for SDKs generated by Kandra. Provides the small surface area
every generated SDK calls into: `Transport`, `Codec`, `Scanner`, `Enrollment`, `IdentityStore`, the `Result` envelope,
and the dispatcher.

This package is the **runtime** dependency of generated SDKs. The code generator itself lives in the sibling
[`kandra`](../kandra/) package and is only needed at build time.

## Install

```bash
pip install kandra-runtime
```

See the [main repository README](../../README.md) for the framework overview and the [Sphinx docs](../../docs/) for
full API reference.
